# CampusLogin

Windows 校园网自动登录助手。

## 项目介绍

CampusLogin 是一个基于 Windows 平台的校园网自动登录工具。

目标是帮助用户自动检测校园网认证状态，并快速完成网络登录。

## 项目目标

- 自动检测校园网连接状态
- 自动打开认证页面
- 自动填写账号密码
- 保存用户登录配置
- 提供简单易用的桌面界面
